## 1. Общее описание

В рамках практической работы разработано консольное приложение на языке Python 3 для получения и анализа зависимостей пакетов дистрибутива **Alpine Linux (`apk`)**.

Проект включает реализацию следующих задач:
1. **Этап 1 (Минимальный прототип с конфигурацией)** — разбор и строгая валидация конфигурационного XML-файла со всеми параметрами, обработка ошибок и вывод параметров в формате `ключ: значение`.
2. **Этап 2 (Сбор данных)** — получение и разбор прямых зависимостей для заданной пользователем версии пакета напрямую из официального сетевого репозитория Alpine Linux (`APKINDEX.tar.gz`) либо из локального файла тестового репозитория.

По требованию задания сторонние менеджеры пакетов и специализированные библиотеки для получения зависимостей не используются — весь разбор реализован вручную с использованием только стандартной библиотеки Python (`urllib.request`, `tarfile`, `gzip`, `xml.etree.ElementTree`).

## 2. Описание всех функций и настроек

Все пользовательские параметры задаются в конфигурационном XML-файле (по умолчанию `config.xml`).

### Список параметров конфигурации:
* `package_name` — имя анализируемого пакета (например, `curl`).
* `repo_url` — URL-адрес репозитория Alpine Linux (например, `https://dl-cdn.alpinelinux.org/alpine/v3.20/main/x86_64`) либо путь к файлу тестового репозитория.
* `test_mode` — режим работы: `true` (для локального тестового файла) или `false` (для реального репозитория).
* `package_version` — конкретная версия пакета (например, `8.14.1-r2`).
* `output_file` — имя файла для сохранения результатов (например, `graph.svg`).
* `max_depth` — максимальная глубина анализа зависимостей (целое положительное число).
* `filter_substring` — подстрока для фильтрации пакетов (например, `so:` для исключения системных динамических библиотек).

Пример файла `config.xml`:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<config>
    <package_name>curl</package_name>
    <repo_url>https://dl-cdn.alpinelinux.org/alpine/v3.20/main/x86_64</repo_url>
    <test_mode>false</test_mode>
    <package_version>8.14.1-r2</package_version>
    <output_file>graph.svg</output_file>
    <max_depth>3</max_depth>
    <filter_substring>so:</filter_substring>
</config>
```

## 3. Описание команд для сборки проекта и запуска тестов

Для работы приложения необходим Python версии 3.10 или выше. Установка сторонних пакетов через `pip` не требуется.

### Запуск приложения:
Скрипты запуска находятся в корне проекта:
- **Windows**:
  ```cmd
  run.bat --config config.xml --stage 2
  ```
- **Linux / macOS**:
  ```bash
  chmod +x run.sh
  ./run.sh --config config.xml --stage 2
  ```
- **Напрямую через Python**:
  ```bash
  python -m src.main --config config.xml --stage 2
  ```
Флаг `--stage` позволяет выбрать этап работы (значения `1` или `2`). По умолчанию запускается этап `2`.

### Запуск тестов:
Все тесты запускаются встроенным тестовым фреймворком `unittest`:
```bash
python -m unittest discover -s tests -v
```

Всего в проекте 20 тестов, разделенных по модулям:
* `tests/test_config.py` — проверка корректности парсинга XML и всех ошибок конфигурации (отсутствие файла, поврежденный XML, пустые обязательные поля, некорректный формат глубины, отсутствие тегов).
* `tests/test_apk_parser.py` — тесты загрузки индекса репозитория, парсинга формата APKINDEX, извлечения версий, очистки версионных префиксов и извлечения прямых зависимостей в реальном и тестовом режимах.
* `tests/test_code_quality.py` — автоматический контроль соблюдения правил оформления кода (длина строк не более 80 символов, размер функций не более 40 строк, не более 7 аргументов, наличие docstrings).

## 4. Примеры использования

### Этап 1. Минимальный прототип с выводом параметров
Команда:
```cmd
python -m src.main --config config.xml --stage 1
```
Вывод в консоль:
```text

repo_url: https://dl-cdn.alpinelinux.org/alpine/v3.20/main/x86_64
test_mode: false
package_version: 8.14.1-r2
output_file: graph.svg
max_depth: 3
filter_substring: so:
```

Команда:
```cmd

```

```text

- libcurl=8.14.1-r2
- so:libc.musl-x86_64.so.1
- so:libcurl.so.4
- so:libz.so.1
```

Вывод в консоль:

- B
- C
